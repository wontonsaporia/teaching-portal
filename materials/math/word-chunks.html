3つの整数の和は72です。
この3つの整数を求めなさい。

Reading 01

問題文の中の数学語彙を見つける

連続する3つの整数があります。
3つの整数の和は72です。
この3つの整数を求めなさい。
連続する 3つの整数 3つの整数の和 72
このページでは、まだ意味の説明も式への変換もしない。まず「どこまでを一つの数学語彙として読むか」を確認する。
数学文章題を読む02 / 08
Chunk 01

数学語彙の意味を知り、式に置きかえる

短い文章 → 式
ある整数 → n
次の整数 → n + 1
さらに次の整数 → n + 2
3つの整数の和 → n + (n+1) + (n+2)
和は72 → n + (n+1) + (n+2) = 72
整数の列では、となり同士の差が1。だから「連続する3つの整数」は1ずつ増える。

Problem 02

連続する3つの偶数

連続する3つの偶数があります。
3つの偶数の和は42です。
この3つの偶数を求めなさい。

「連続する」の意味は同じ。でも、今見ている数の列が変わりました。
数学文章題を読む05 / 08
Chunk 02

「連続する」は、どの列を見ているかで変わる

連続するある規則にしたがって順番に並べた数の列の中で、間に別の数を挟まず隣り合っていること。
偶数2で割り切れる整数。… −4, −2, 0, 2, 4, 6, 8, … のように並ぶ。
色のついた部分を、ひとまとまりとして読む
連続する3つの偶数があります。
3つの偶数の和は42です。
この3つの偶数を求めなさい。
整数の列では1ずつ、偶数の列では2ずつ進む。「連続する＝差が1」ではなく、「その列の中でとなり同士」。

Translate 02

偶数の列を、式に置きかえる

短い文章 → 式
ある偶数 → 2n
次の偶数 → 2n + 2
さらに次の偶数 → 2n + 4
3つの偶数の和 → 2n + (2n+2) + (2n+4)
和は42 → 2n + (2n+2) + (2n+4) = 42
